# EduBridge — хөнгөн demo

## Ажиллуулах
1. ZIP файлыг Extract All хийж задална.
2. EduBridge-demo хавтас дахь index.html файлыг Chrome эсвэл Edge дээр нээнэ.
3. «Бүртгүүлэх» сонгож нэр, имэйл, 6-аас доошгүй тэмдэгттэй туршилтын нууц үг оруулна.

npm install, pnpm, Node.js, сервер, өгөгдлийн сан, интернэт шаардлагагүй.
Хуучин төслийн хавтас дотор хуулж холихгүй. Тусдаа задалж нээнэ.

## GitHub Pages-д нийтлэх
Repository: `https://github.com/enhjin831/EduBridge-demo`

1. GitHub дээр `EduBridge-demo` нэртэй **public** repository үүсгэнэ.
2. Энэ хавтасны бүх файлыг repository-ийн `main` branch руу upload хийнэ.
3. `.github/workflows/pages.yml` файл upload хийгдсэн эсэхийг шалгана.
4. GitHub-ийн **Settings → Pages** хэсэгт Source-ийг **GitHub Actions** болгоно.
5. Workflow амжилттай дууссаны дараа demo дараах URL-аар нээгдэнэ:
   `https://enhjin831.github.io/EduBridge-demo/`

## Үзүүлэх дараалал
Монгол хэрэглэгчээр бүртгүүлэх → түвшинд тохирсон хажуугийн цэс → их сургууль/тэтгэлэг/Work and Travel/солилцооны карт → хайлт/шүүлтүүр → дэлгэрэнгүй → хадгалах → Pro/Premium/Global Ready багц сонгох → нэмэлт асуумж → AI тохирцын demo хувь → Premium менторын цаг сонгох → уулзалтад орох → профайл засах → гарах.


## Хамрах хүрээ
- Монгол хэрэглэгчийн бүртгэл, үндсэн мэдээлэл, боловсролын түвшин/суралцах төлөвийн асуумж ажиллана.
- Түвшинд тохирсон хажуугийн цэс, сургууль/тэтгэлэг/хөтөлбөрийн карт, дэлгэрэнгүй modal ажиллана.
- Free, Pro, Premium, Global Ready гишүүнчлэлийн дэлгэц, нэмэлт Pro/Premium асуумж, demo AI тохирцын хувь ажиллана.
- Premium менторын профайл, цаг товлох, цуцлах, Zoom холбоосын demo товч ажиллана.
- Нэр, багц, асуумж, хадгалсан боломж, цаг сонголт localStorage-д хадгалагдана.
- Session хадгалагдах тул хуудсаа шинэчлэхэд нэвтэрсэн хэвээр байна.
- Бүртгэл нь зөвхөн тухайн компьютер/браузер/файлын байршилд хамаарна.
- Браузерийн өгөгдлийг цэвэрлэхэд demo бүртгэл арилна.
- Энэ нь бодит нэвтрэлт хамгаалалтгүй локал UI demo. Нууц үг localStorage-д энгийн текстээр хадгалагдана. Бодит нууц үг, хувийн мэдээлэл ашиглахгүй.
- Бүх хөтөлбөр, ментор жишээ. AI үнэлгээ, бодит төлбөр, мэдэгдэл, өргөдөл, Zoom уулзалт, серверийн захиалга байхгүй.
